# Panduan: Dashboard & Monitoring Klinis 📊

Modul Dashboard adalah pusat kendali visual rumah sakit yang memberikan gambaran umum tentang status operasional secara real-time.

## 🚀 Fitur Utama

### 1. Dashboard Utama (Clinical Overview)
Memberikan informasi cepat mengenai:
*   **Okupansi Bed**: Jumlah bed terisi vs tersedia di seluruh bangsal.
*   **Antrean IGD/Triase**: Jumlah pasien yang sedang menunggu penilaian medis.
*   **Indikator Stress**: Tingkat beban kerja staf (Hook Stress Monitor).

### 2. Executive Dashboard
Dirancang untuk jajaran manajemen guna memantau:
*   **KPI Operasional**: Rata-rata waktu tunggu pasien (Waiting Time).
*   **Statistik Kunjungan**: Tren pasien harian, mingguan, dan bulanan.
*   **Revenue Monitoring**: Status billing dan klaim (tergantung hak akses).

### 3. Pelaporan Insiden (GLD Report)
Fitur untuk melaporkan kejadian yang mengancam keselamatan pasien atau aset (Greatest Common Loss/Disaster).
*   **Cara Melapor**: Klik menu "GLD Report", pilih kategori kejadian, dan deskripsikan insiden secara detail.
*   **Anonymity**: Laporan dapat bersifat rahasia untuk mendorong budaya keselamatan (Just Culture).

## 📖 Cara Penggunaan

1.  **Navigasi**: Pilih menu **Dashboard** pada sidebar navigasi utama.
2.  **Filter Data**: Gunakan dropdown tanggal atau unit untuk mempersempit tampilan data.
3.  **Detail Item**: Klik pada metrik tertentu (misal: jumlah pasien IGD) untuk melihat daftar pasien yang terkait.

---

## ⚠️ Perhatian Keamanan (JCI)
*   **Data Privasi**: Dilarang mengambil tangkapan layar (screenshot) dashboard yang mengandung data identitas pasien untuk tujuan non-klinis.
*   **Keakuratan**: Jika terdapat anomali data (misal: bed terisi padahal fisik kosong), segera lakukan sinkronisasi melalui menu Administrasi Bangsal.

> [!TIP]
> Gunakan mode "Focus Mode" jika Anda perlu fokus pada satu metrik data tanpa gangguan notifikasi sistem lainnya.
