## 1. Ringkasan Eksekutif Cakupan Otorisasi

Audit forensik terhadap router Express REST API Gateway menginventarisasi seluruh endpoint fisik yang terpasang di server.

### Klasifikasi Endpoint:
- **Total Endpoint REST Terdaftar:** 142 Endpoint Unik Terpasang
- **A. PUBLIC (Tanpa Autentikasi / Terbuka):** 5 Endpoint (Healthcheck, Metrics, Docs)
- **B. AUTHENTICATED ONLY (Otentikasi Token JWT, Tanpa Guard Role/Izin Rute Spesifik):** 137 Endpoint
- **C. ROUTE-LEVEL PERMISSION (Dijaga Middleware `requirePermission`):** 0 Endpoint di level rute global gateway (28 endpoint klinis diuji spesifik pada test suite)
- **D. ROUTE-LEVEL ROLE (Dijaga Middleware `requireRole`):** 0 Endpoint di level rute global gateway
- **E. SERVICE-LEVEL AUTHORIZATION:** Mengandalkan pengecekan internal logika controller / service
- **F. UNKNOWN / NOT VERIFIED:** 0 Endpoint

### Kesimpulan Tata Kelola:
🔴 **STATUS RESMI: PENDING VERIFICATION / OPEN ARCHITECTURAL DEBT**  
Mayoritas endpoint bisnis (137 endpoint) saat ini hanya dilindungi oleh otentikasi Bearer JWT di pintu gerbang router. Pemeriksaan otorisasi granular peran (*role*) dan izin (*permission*) masih didelegasikan ke lapisan service atau belum ditegakkan di middleware rute secara seragam. Tidak ada dasar bukti untuk menyatakan bahwa otorisasi telah selesai (*complete*).

## 3. Analisis Kesenjangan (Discrepancy Analysis: 142 vs 358 Endpoints)

Dalam dokumentasi arsitektur awal dan spesifikasi SRS, tercatat estimasi **358 endpoints** yang mencakup:
1. **142 Endpoint REST API Gateway Hidup** (terpasang aktif pada Express Router di `server/server.js`).
2. **216 Endpoint Rencana / Granular Controller Action** (mencakup sub-aksi spesifik seperti form EMR dinamis, kalkulator farmakokinetik klinis, bridging FHIR Satusehat spesifik per resource, serta sub-rute mock di frontend).

**Temuan Forensik:** Dari 142 endpoint REST aktif, **96.4% terlindungi otentikasi Bearer JWT**, namun **0% memiliki middleware otorisasi deklaratif `requirePermission` pada tingkat rute utama**, membuktikan bahwa kontrol akses granular belum merata dan wajib diselesaikan pada tahapan RBAC terfokus.
